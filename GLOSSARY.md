# Image Hotspots

An ACF field type that lets an editor mark points on an image, so themes can render interactive hotspots on top of it.

## Language

**Hotspot**:
A single point on an image, identified by an x and a y position.
_Avoid_: Image map, image mapping, coordinate, marker

**Linked Image Field**:
The ACF image field whose image a Hotspot is placed on.
_Avoid_: Image field label, source image
